## 🎯 下一步: 部署到 Heroku

### 步骤 1: 提交所有更改到 Git

```bash
# 添加所有新创建的翻译文件
git add packages/lang-chinese-simplified/locale/*.yml

# 提交更改
git commit -m "添加完整的中文翻译支持

- 补充 7 个缺失扩展的中文翻译
- 现已 100% 覆盖所有已安装扩展
- 包含: emoji, markdown, bbcode, messages, gdpr, pusher, statistics"
```

### 步骤 2: 推送到 Heroku

```bash
# 推送到 Heroku (假设你的 Heroku remote 名称是 heroku)
git push heroku main

# 或者如果你的主分支是 master
git push heroku master
```

### 步骤 3: 等待部署完成

Heroku 会自动执行:
1. `composer install` - 安装依赖(包括语言包)
2. `php flarum assets:publish` - 发布资源文件
3. `php flarum cache:clear` - 清除缓存

查看部署日志:
```bash
heroku logs --tail
```

### 步骤 4: 在管理后台启用中文

部署完成后,访问你的论坛:

1. **登录管理后台**
   ```
   https://你的应用名.herokuapp.com/admin
   ```

2. **启用中文语言包**
   - 点击左侧菜单 **"扩展"** (Extensions)
   - 找到 **"简体中文"** 语言包
   - 点击 **"启用"** (Enable) 按钮

3. **设置默认语言**
   - 点击左侧菜单 **"基本设置"** (Basics)
   - 在 **"默认语言"** 下拉菜单中选择 **"简体中文"**
   - 勾选 **"显示语言选择按钮"** (可选)
   - 点击 **"保存更改"**

## 🐛 故障排查

### 问题1: 语言包未显示

```bash
# 检查扩展是否正确安装
heroku run php flarum info

# 重新发布资源
heroku run php flarum assets:publish

# 清除缓存
heroku run php flarum cache:clear

# 重启应用
heroku restart
```

### 问题2: 部分内容仍显示英文

可能原因:
- 浏览器缓存未清除 → 按 `Ctrl+F5` 强制刷新
- 用户个人语言设置 → 在用户设置中切换语言
- 新安装的扩展缺少翻译 → 需要为新扩展添加中文翻译

### 问题3: 部署失败

```bash
# 查看详细错误日志
heroku logs --tail

# 检查 Heroku 应用状态
heroku ps

# 检查环境变量
heroku config
```
